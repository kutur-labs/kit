`/anti-slop` reports vague words such as `lands` or `leverage` and dashes used as punctuation in comments, through the new `kit/comment-prose` rule. The new `kit-prose` command reports the same in Markdown files and can hold a file to a character budget. When upgrading, reword what the rule reports, or put a literal use in a code span.
